# 📊 HR Analytics Dashboard (Microsoft Excel)

## 📌 Project Overview

This project presents an interactive HR Analytics Dashboard developed using Microsoft Excel. The dashboard helps HR teams analyze employee attrition, workforce demographics, job satisfaction, and department-level trends to support data-driven decision-making.

---

## 🎯 Objectives

- Analyze employee attrition patterns.
- Monitor workforce demographics.
- Identify departments with high attrition.
- Track employee distribution by gender and age.
- Understand the impact of education and job roles on attrition.

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Dashboard Design

---

## 📊 Key Performance Indicators (KPIs)

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Employee Age
- Job Satisfaction Rating

---

## 📈 Dashboard Features

- Employee distribution by gender
- Department-wise attrition
- Job role attrition
- Education-wise attrition
- Age-wise attrition
- Marital status analysis
- Interactive slicers for filtering

## 💡 Business Insights

- Sales department recorded the highest employee attrition.
- Employees aged 25–34 showed the highest attrition.
- Life Sciences and Medical education backgrounds contributed the highest attrition counts.
- Single employees had higher attrition compared to married and divorced employees.
